Regex File Search

ECE 3331 Final Project

How It Works

Upload a text file and enter a regex pattern to search for matches. The results will show each line containing matches with the matched text highlighted.

Supported Regex Features:

  • ^ - Start of line
  • $ - End of line
  • . - Any single character
  • * - Zero or more of previous character
  • + - One or more of previous character
  • ? - Zero or one of previous character
  • [abc] - Any character in brackets
  • {n} - Exactly n occurrences
  • {n,m} - Between n and m occurrences
  • (?i) - Case insensitive matching

Example Patterns

h.llo
Find "hello", "hallo", "hxllo", etc.
^The
Find lines starting with "The"
end$
Find lines ending with "end"
a{2,4}
Find "aa", "aaa", or "aaaa"
colou?r
Find "color" or "colour"
[aeiou]{3}
Find three consecutive vowels
